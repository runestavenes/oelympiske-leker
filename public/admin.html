Teams

Activities

Edit values and click Save. Activities with "In Schedule" checked are included in the round-robin.

Pre-Tournament Scores

Enter individual team results for activities played before the main tournament. Win = 3 pts, Draw = 2 pts, Lose = 0 pts.

Romantiske observasjoner

Each observation gives a team 1 win on the dashboard (no points). Type a description and select a team.

Schedule

Full round-robin = teams − 1 rounds. More rounds repeat pairings; fewer rounds give a partial schedule.

Tournaments

One tournament is active at a time — all phones and the dashboard show the active one. Create a new empty tournament for a new event, or reopen an old one.

Data Management

Export/import applies to the active tournament. Reset clears all data in the active tournament.
